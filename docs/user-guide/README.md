# User guide

How to use the Maxx Sales Training portal. Pick the guide for your role (it's shown in the menu under your initials):

- [Learners](learners.md): taking courses, assessments and certificates
- [Managers](managers.md): following your team's training
- [Admins and super admins](admins.md): courses, questions, training groups and helping people

## Words used in the portal

| Word | Meaning |
|---|---|
| **Course** | A set of reading (one or more PDFs) and usually an assessment |
| **Deck** | One PDF in a course |
| **Reading question** | A question that appears while reading, at a certain page |
| **Assessment** | The test at the end of a course |
| **Mandatory question** | An assessment question that's always asked and must be answered correctly to pass |
| **Reading only** | A course with no assessment; finishing the reading completes it |
| **Required course** | A course assigned to you, directly or through a training group |
| **Training group** | A group of people, set up by admins, who are assigned the same courses |
| **Watchlist** | A private list of people a manager or admin follows; doesn't change anyone's training |
| **Compliant** | Every required course has been passed |
| **Archived** | A retired course: no longer available, results kept |
